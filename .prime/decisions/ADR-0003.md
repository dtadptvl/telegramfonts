# Vietnamese AI cascade

## Decision
- ORIGINAL mode makes zero AI calls.
- VIETNAMESE mode preserves existing glyphs/metrics/behavior and invokes AI only for missing Vietnamese coverage.
- Deterministic geometry, anchors, NFC/NFD, OpenType, collision, corpus, four-consumer and held-out gates remain authoritative over any AI output.

## Model route (exact, no substitution)
- Woku base: `https://llm.wokushop.com/v1`
- Woku exact route:
  1. `gpt-5.6-luna` PRIMARY
  2. `gemini-3.7-flash` fallback
- Downstream OpenRouter route remains:
  1. `google/gemma-3-12b-it`
  2. `google/gemma-3-27b-it` for DIFFICULT only
  3. `google/gemini-3.1-flash-lite` as RARE FINAL ARBITER only

## Constraints
- No model substitution, retry loop, validator bypass, or cross-provider unbound cache reuse.
- Provenance binds provider/model/route/fallback reason/prompt/schema/config/source/candidate identity.
- Local secret key names only: `wokushop_api_key`, `openrouter_api_key`. Never persist/read/report secret values.
- Current external provider availability/attestation is runtime evidence, not permanent architectural truth.

## Consequences
- FAST_30 regime (ADR-0001) does not alter this cascade; VIETNAMESE extension stage in the release gate must keep these routes and provenance bindings.
