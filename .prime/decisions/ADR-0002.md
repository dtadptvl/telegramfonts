# Product fulfillment and acquisition invariants

## Architecture boundary
- Cloudflare Worker (edge/) terminates Telegram + SePay.
- D1 is the canonical order/payment/job/outbox state.
- Queue is at-least-once; R2 is private; the compute plane (A23 agent) is outbound-only.

## /muahang flow (invariant order)
ORIGINAL|VIETNAMESE -> MyFonts URL -> catalog/styles -> TTF|OTF -> exact price -> verified SePay payment -> reuse/acquisition/compute -> all-or-nothing validation/package -> Telegram sendDocument.
- No heavy acquisition/compute before verified payment.
- No partial multi-style/multi-format delivery (all-or-nothing).

## Post-payment reuse ladder (precedence order)
L1 exact final artifact -> L2 canonical FontModel -> L3 authorized binary -> L4 exact raster observations -> source acquisition.
An exact compatible repeat hit skips every downstream stage it causally replaces.

## Acquisition exact order
1. native Chrome/Edge `--headless=new --dump-dom`;
2. Playwright Stealth with persistent authorized cf_clearance for dynamic raster + metrics;
3. Monotype CDN complete crawl when exact MD5 exists;
4. Algolia obtains the full style-to-MD5 map when MD5 is absent, then return to CDN.
- A valid authorized binary found at any method wins immediately.
- Partial/incomplete raster is never success; continue all applicable fallbacks.
- TTF/OTF binaries may pass directly.
- WOFF/WOFF2 are authorized INPUT containers only, normalized to attested sfnt; never product output.
- Product output is TTF+OTF only.

## Pricing rule (approved)
- ORIGINAL: 5,000 VND/style.
- VIETNAMESE: 8,000 VND/style.
(Implementation status is tracked in state.blockers; this reconciliation does not change pricing.)

## Constraints
- Portable typed ports/adapters remain mandatory.
- No secret/cookie/provider authorization material enters Git, logs, or evidence.

## Consequences
- T-A23-PROD-01 and any production dispatch contract must honor these invariants; reuse ladder and all-or-nothing delivery semantics cannot be weakened by recovery work.
